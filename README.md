# ForTemLabs Metrics

Hi there! 👋 Welcome to the official metrics page for **ForTemLabs**.

ForTemLabs builds [Fortem](https://github.com/ForTemLabs/fortem), a Sui blockchain-based NFT marketplace, along with the dApps and tooling around it.

This repository uses **GitHub Metrics** to automatically track and visualize our team's development activity — including commits, pull requests, issues, languages used, and contributions across repositories.
